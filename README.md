# До рассвета — Игровой веб-компаньон

Кооперативный гибридный (phygital) настольный триллер на выживание.
Веб-приложение для одного общего устройства (ноутбук, планшет или ТВ/проектор) с камерой для считывания QR-кодов.

## Быстрый запуск

Запустите скрипт:
```bash
./start.sh
```
Или вручную:
```bash
./node_modules/.bin/vite --host 0.0.0.0 --port 3000
```
Приложение откроется по адресу: **http://localhost:3000** (или по локальному IP планшета в домашней сети Wi-Fi).

## Архитектура проекта

- `src/types/game.ts` — TypeScript-схема сценариев, комнат, кризисов, моральных дилемм и состояния игры.
- `src/data/scenarioChapter1.ts` — Контент первого сценария («Глава 1: Падение комплекса Аврора»). Все комнаты, QR-коды, подсказки и логика зомби хранятся декларативно.
- `src/components/BuildingMap.tsx` — Интерактивная 2D-карта 14 этажа со статусами комнат (Открыта, Заперта, Туман войны, Осада).
- `src/components/RoomView.tsx` — Экран комнаты с дедуктивными зацепками обстановки, функцией Координатора (CCTV) и интерактивными объектами.
- `src/components/QRScannerModal.tsx` — Сканер QR через веб-камеру (`jsqr`) + обязательный мгновенный ввод 3-значного цифрового кода (для плохой освещенности).
- `src/components/ThreatModal.tsx` — Директивы фазы угроз (расчет появления и миграции зомби для физического стола).
- `src/components/DilemmaModal.tsx` — Моральные выборы команды с мгновенными сюжетными последствиями.
- `src/components/VideoOverlayModal.tsx` — Кинематографический плеер для ключевых сюжетных поворотов (запуск генератора, взлом сейфа).
- `src/utils/audio.ts` — Процедурный звуковой движок на Web Audio API (работает офлайн без сторонних mp3).
- `src/utils/wakeLock.ts` — Предотвращение засыпания экрана планшета/ТВ во время партии (Screen Wake Lock API).
